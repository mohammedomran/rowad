# رواد — واجهة الموقع

واجهة ثابتة (HTML/CSS/JS بلا أدوات بناء) لمنصة قصص الأطفال «رواد»، للأعمار من 3 إلى 9 سنوات، بالعربية الفصحى واتجاه RTL.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًّا:

```bash
node tools/serve.mjs . 5173   # ثم افتح http://127.0.0.1:5173
```

تسجيل الدخول تجريبي: أي بريد صحيح الصيغة مع أي كلمة مرور يفتح حسابًا تجريبيًّا فيه بيانات جاهزة. إنشاء حساب جديد يبدأ بحساب فارغ (لرؤية الحالات الفارغة).

## البنية

```
assets/css/rowad.css   نظام التصميم كاملًا (الرموز في :root أعلى الملف)
assets/js/data.js      كتالوج القصص والتصنيفات والصور الرمزية
assets/js/app.js       الحالة، طبقة API، الهيكل المشترك، البطاقات، النوافذ، المشغّل
assets/js/pages.js     منطق كل صفحة بحسب <body data-page>
assets/js/guard.js     حارس الصفحات (يُحمَّل في <head>)
assets/js/icons.js     أيقونات SVG (مولَّد — لا يُعدَّل يدويًّا)
assets/js/pwa.js       تسجيل عامل الخدمة وزر «حمّل التطبيق» العائم
sw.js                  عامل الخدمة: التخزين والعمل دون اتصال
manifest.webmanifest   بيانات التطبيق المثبَّت (الاسم، الأيقونات، الاختصارات)
assets/img/            الصور بصيغة WebP
ui/generated/          الرسوم الأصلية بدقتها الكاملة (PNG)
tools/                 سكربتات مساعدة (Node + ffmpeg)
```

## تطبيق الويب (PWA)

الموقع قابل للتثبيت كتطبيق على أندرويد وiPhone والحاسوب، ويعمل دون اتصال بعد أول زيارة.

- **زر «حمّل التطبيق»** عائم أسفل يسار كل الصفحات (فوق الشريط السفلي في الجوال). في Chrome/Edge/Samsung يفتح نافذة التثبيت الأصلية، وفي iPhone/iPad يعرض خطوات «إضافة إلى الشاشة الرئيسية»، وفي غيرها يعرض خطوات التثبيت من قائمة المتصفح. يختفي تلقائيًّا داخل التطبيق المثبَّت.
- **عامل الخدمة** `sw.js`: الصفحات وCSS/JS بالشبكة أولًا ثم المحفوظ، والصور من المحفوظ أولًا، والخطوط ومكتبات CDN تُحدَّث في الخلفية. الفيديو لا يُخزَّن.
- **عند كل نشر**: غيّر `VERSION` في `sw.js` لتُحذف النسخ القديمة. وإن أضفت صفحة أو ملف JS جديدًا فأضفه إلى `SHELL_FILES`.
- **الشرط**: يعمل عامل الخدمة على HTTPS فقط (أو `localhost` / `127.0.0.1` للتجربة).

## ما يحتاج إلى ربط قبل النشر

كل ما يلي يعمل الآن في المتصفح فقط (`localStorage`):

- **المصادقة**: `Rowad.api` في `app.js` — أربع دوال، كل واحدة تقابل نقطة API. الحارس `guard.js` للواجهة فقط؛ الحماية الحقيقية في الخادم.
- **الفيديو**: ضع الرابط في حقل `video` لكل قصة أو حلقة في `data.js`. ما دام `null` يعرض المشغّل حالة «قريبًا».
- **التنزيلات**: تُحفَظ قائمة فقط، ولا يُخزَّن ملف للمشاهدة دون اتصال.
- **البيانات التجريبية**: الدالة `seedDemo` في `app.js` تُحذف عند الربط.
- **الشروط والخصوصية**: خانة الموافقة في `signup.html` بلا روابط؛ أضف الصفحتين واربطهما.
- **روابط المشاركة**: `og:image` و`canonical` في `index.html` تحتاج اسم النطاق.

## مهام شائعة

- **قصة جديدة**: أضف عنصرًا إلى `stories` في `data.js` مع غلاف بنسبة 3:2 في `assets/img/covers/`.
- **أيقونة جديدة**: أضف اسمها (من [Phosphor](https://phosphoricons.com)) إلى `tools/build-icons.mjs` ثم `node tools/build-icons.mjs assets/js/icons.js`.
- **لون أو خط**: عدّل الرموز في `:root` أعلى `rowad.css`.
